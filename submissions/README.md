# Конкурсный сабмит (`submissions/`)

* **`submission_probe_35.csv`** — лучший автоматический ответ команды на платформе КосмоХакатона 2026 (**Score `0.7455`**; итоговая оценка жюри по кейсу — **83,67 / 100**, **19-е место из 47 команд**).
* **Конфигурация:** [`weights/weights_probe_35.json`](../weights/weights_probe_35.json) → [`weights/severity_model_p35.pkl`](../weights/severity_model_p35.pkl) (`majority 3 × 3`, `min_patch_px = 96`, `af.k_sigma = 2.5`).
* **Состав:** заголовок + **447 строк** (`180` чипов AF × 1 класс + `89` чипов BS × 3 класса степени поражения = `269` тестовых чипов).
* **Целостность RLE:** проверена автоматически в [`.github/workflows/ci.yml`](../.github/workflows/ci.yml) — строгий порядок пар `start length` (1-индексация), отсутствие выхода за границы чипа (`256×256` для AF, `512×512` для BS) и 0 пересекающихся пикселей между классами `1`, `2` и `3`.
* История всех проб и откатов — в [`docs/experiments.md`](../docs/experiments.md).
